# python-forex

Important notes about free packages and apis for downloading forex data.

Packages:

- [`forex-python`][1],
- [`yfinance`][2],
- [`currencyapicom`][3].

APIs:

- [`The Rates API`][4],
- [`exchangerates`][5],
- [`currencyapi`][6],
- [`ExchangeRate-API`][7],
- [`ECB API`][8],
- [`Alpha Vantage`][9].

# Packages

## `forex-python`

Use api: https://theratesapi.com/
- non-required api key
- unlimited requests per month
- unavailable time series

## `yfinance`

Use api: unofficial Yahoo endpoints
- non-required api key
- unlimited requests per month
- available time series

## `currencyapicom`

Use api: https://currencyapi.com/
- required api key
- 300 free requests per month
- paid time series

# APIs

## `The Rates API`

- non-required api key
- unlimited requests per month
- unavailable time series

## `exchangerates`

- required api key
- 100 free requests per month
- paid time series

## `currencyapi`

- required api key
- 300 free requests per month
- paid time series

## `ExchangeRate-API`

- required api key
- 1,500 free requests per month
- paid time series

## `ECB API`

- non-required api key
- unlimited requests per month
- available time series

## `Alpha Vantage`

- required api key
- unlimited requests per month
- available time series
